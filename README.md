## 📈 Projects

### 1️⃣ Employee Report - HR Analytics Dashboard

**Folder**: `EmployeeReport/`

A comprehensive HR analytics dashboard analyzing workforce demographics, distribution, and key metrics to support organizational decision-making.

**Key Features:**
- Employee demographics and gender distribution analysis
- Organizational insights by department and location
- Interactive filters for dynamic data exploration
- Key HR KPIs and performance metrics

**Technologies**: Power BI, Excel  
**Dataset**: Employee information (Employees.xlsx)

📁 [View Project Details](./EmployeeReport/README.md)

---

### 2️⃣ Medical Insurance Cost Analysis

**Folder**: `MedInsuranceReport/`

An in-depth analysis of medical insurance costs exploring relationships between demographic factors, lifestyle choices, and insurance premiums.

**Key Features:**
- Impact of age, BMI, and smoking on insurance charges
- Regional cost variations across the United States
- Family size and demographic correlation analysis
- Statistical distribution of insurance premiums

**Technologies**: Power BI, CSV  
**Dataset**: 1,340 insurance records from [Kaggle](https://www.kaggle.com/datasets/mosapabdelghany/medical-insurance-cost-dataset)

📁 [View Project Details](./MedInsuranceReport/README.md)

---

### 3️⃣ Superstore Sales Analysis

**Folder**: `SuperstoreReport/`

A comprehensive retail sales analysis covering 9,994 transactions from a fictional superstore, providing insights across geography, products, and customer segments.

**Key Features:**
- Sales performance trends (2014-2017)
- Product category and sub-category analysis
- Customer segmentation insights (Consumer, Corporate, Home Office)
- Geographic performance by US regions
- Profitability and discount impact analysis

**Technologies**: Power BI, CSV  
**Dataset**: 9,994 transaction records from [Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

📁 [View Project Details](./SuperstoreReport/README.md)

## 🚀 Getting Started

### Prerequisites

To view and interact with these Power BI reports, you'll need:

- **Power BI Desktop** (Free download)
  - Download from: [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/)
  - Recommended: Latest version for full compatibility

### How to Use This Repository

1. **Clone or download** this repository to your local machine
2. **Navigate** to the project folder you're interested in
3. **Open** the `.pbix` file with Power BI Desktop
4. **Explore** the interactive dashboards and visualizations
5. **Refer** to individual README files for project-specific details

### Viewing Reports

Each project folder contains:
- **`.pbix` file**: Power BI report file (open with Power BI Desktop)
- **`.gif` file**: Animated preview of the dashboard
- **Data files**: Source datasets (Excel/CSV)
- **README.md**: Detailed project documentation
